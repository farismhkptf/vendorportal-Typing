Objective:

- Outlook Desktop (Windows – primary priority)
- Outlook on Laptop
- Mobile devices (iOS Mail, Gmail app, Outlook mobile)

Critical Requirement:
The appearance in Outlook Desktop must match exactly how the design appears in current preview. No layout shifts, font inconsistencies, spacing issues, or alignment breaks are acceptable.

  - Headings
  - Subheadings
  - Body text
  - Labels / metadata

2. Layout & Spacing
- Ensure consistent padding and margins across all sections
- Fix any spacing collapse issues in Outlook (especially table-based layouts)
- Maintain visual balance and alignment identical to preview

3. Email Structure (Outlook Compatibility)
- Convert layout fully into table-based structure where required
- Eliminate reliance on unsupported CSS (flex, grid, etc.)

4. Scaling & Responsiveness
- Desktop (Outlook): fixed, pixel-perfect layout
- Mobile:
  - Proper stacking of sections
  - Readable font sizes (no zoom required)

5. Cross-Client Consistency
- Test and optimize for:
  - Outlook Desktop (highest priority)

6. Visual Fidelity
- Ensure:
  - Colors render correctly
  - Line heights are consistent
  - No unexpected bolding or font substitution
- Match preview design exactly in Outlook

7. Fallback Handling
- Define fallbacks for:
  - Fonts
  - Buttons (bulletproof buttons for Outlook)

8. Deliverable
- Final HTML email template
- Fully tested for Outlook Desktop accuracy
