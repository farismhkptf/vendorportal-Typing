Medical Centers - Details & Scheduling Logic
Medical Center Data Structure
Each medical center has:
	•	Type: DHA (Dubai Health Authority) or EHS (Emirates Health Services)
	•	Tier: normal or vip (VIP centers for premium clients)
	•	Address: Physical location
	•	Location Map URL: Google Maps link
	•	Timing Text: Human-readable hours
	•	Timings: Structured JSON for each day of the week

Timing Data Structure
Each day has:
{
open: "07:00", // Opening time (24h format)
close: "21:30", // Closing time
breakStart: "11:30", // Optional: Friday prayer break start
breakEnd: "14:00", // Optional: Friday prayer break end
closed: true // Optional: If center is closed this day
}


Current Scheduling Logic
What's Implemented:
	1	VIP Auto-Selection: When scheduling for a VIP work order, system auto-selects the company's VIP favorite medical center
	2	Normal Auto-Selection: Non-VIP work orders get the company's normal favorite center
	3	Company Favorites: Each company can set preferred normal and VIP centers
	4	Date/Time Selection: User picks appointment date and time manually
	5	Center Snapshot: When scheduled, the center's details are saved as a snapshot (preserves data if center info changes later)
What's NOT Implemented Yet:
	1	Time Validation: No check if selected time falls within center's operating hours
	2	Break Time Validation: No check for Friday prayer breaks (11:30AM-2PM typically)
	3	Closed Day Validation: No check if center is closed on selected day
	4	Conflict Detection: No check for double-booking same staff at same time

Scheduling Logic - Current Implementation
1. Center Selection Flow
User enters WO Number
↓
System looks up Work Order
↓
Gets Company → Favorite Medical Centers
↓
If WO is VIP → Auto-select VIP Favorite Center
If WO is Normal → Auto-select Normal Favorite Center
↓
User can override selection

2. Data Captured When Scheduling
	•	Work Order ID - Links appointment to WO
	•	Medical Center ID - Selected center
	•	Medical Center Snapshot - Saves center name, address, map URL, timing at time of booking
	•	Appointment Date - YYYY-MM-DD format
	•	Appointment Time - HH:MM format (24h)
	•	Is VIP - Boolean flag for VIP treatment
	•	Relationship Manager - Name, phone, email (optional)
	•	Escort - Name, phone, email for person accompanying applicant (optional)
3. Auto-Email Generation
When appointment is scheduled:
	1	System finds/creates "Medical Scheduling" email milestone
	2	Creates draft email with pre-filled content:
	•	Staff name
	•	Appointment date/time
	•	Medical center name & address
	•	Google Maps link
	3	Email appears in dashboard under "To Draft" or "Ready to Send"
