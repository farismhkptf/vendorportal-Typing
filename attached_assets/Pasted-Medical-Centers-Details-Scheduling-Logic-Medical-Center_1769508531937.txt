Medical Centers - Details & Scheduling Logic
Medical Center Data Structure
Each medical center has:

Type: DHA (Dubai Health Authority) or EHS (Emirates Health Services)
Tier: normal or vip (VIP centers for premium clients)
Address: Physical location
Location Map URL: Google Maps link
Timing Text: Human-readable hours
Timings: Structured JSON for each day of the week

Timing Data Structure
Each day has:

{
  open: "07:00",      // Opening time (24h format)
  close: "21:30",     // Closing time
  breakStart: "11:30", // Optional: Friday prayer break start
  breakEnd: "14:00",   // Optional: Friday prayer break end
  closed: true         // Optional: If center is closed this day
}
Current Scheduling Logic
What's Implemented:
VIP Auto-Selection: When scheduling for a VIP work order, system auto-selects the company's VIP favorite medical center
Normal Auto-Selection: Non-VIP work orders get the company's normal favorite center
Company Favorites: Each company can set preferred normal and VIP centers
Date/Time Selection: User picks appointment date and time manually
Center Snapshot: When scheduled, the center's details are saved as a snapshot (preserves data if center info changes later)
What's NOT Implemented Yet:
Time Validation: No check if selected time falls within center's operating hours
Break Time Validation: No check for Friday prayer breaks (11:30AM-2PM typically)
Closed Day Validation: No check if center is closed on selected day
Conflict Detection: No check for double-booking same staff at same time
