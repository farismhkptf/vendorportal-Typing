You have ONE vendor handling BOTH medical and EID typing.

Vendor can see ALL jobs you assigned (new and old).

Typing Job Types + vendor costs (fixed):
- Medical Typing – Normal: 290
- Medical Typing – VIP: 720
- Emirates ID Application – 1 Year: 270
- Emirates ID Application – 2 Year: 370
- Emirates ID Application – 10 Years: 1200
- Emirates ID Replacement: 470

Typing job outputs:
- Medical: application reference number + center details + attachments (pdf/images)
- EID: same + if biometrics required then biometrics date/time + center (vendor knows which needs biometrics)
Rules:
- For Medical: internal team decides appointment date/time separately.
- For EID biometrics: vendor returns gov-provided date/time if applicable.

Typing Job statuses:
- Draft
- Sent to Vendor
- In Progress

- Returned (Cost Deducted)
- Sent to Client
- Vendor Mistake (Refunded)
- Cancelled

- Internal team can still mark “Sent to Client” after they inform client.

Rework/issue handling:
- Internal can mark “Vendor Mistake” with reason (required).
- When marked, system reverses the wallet debit for that job (refund back).
- Keep full audit trail.

Comments:
- Each typing job has a comment thread internal+vendor.

- Input docs to vendor: PDF/images (from WorkDrive)
- Output docs from vendor: PDF/images (to WorkDrive)

- Top-ups are CREDITS.
- Each Returned job is a DEBIT for its fixed cost.
- Vendor Mistake triggers REVERSAL credit for same amount.
Low balance threshold: 1000 (show banner + dashboard alert).
Accounting screens:
1) Vendor Wallet Summary (balance, month spend, month top-ups, low balance alert)
2) Vendor Ledger (filter by date range, export CSV)
3) Vendor Statements (auto-generate statement for period; vendor can also upload invoice PDF)
Payments tracking states:
- Track all (unbilled, billed, paid) via ledger/statement metadata.
